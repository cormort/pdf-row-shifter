# PDF 資料列分頁調整

瀏覽器裡直接調整 PDF 表格的分頁位置，不用重排原始文件。單一 HTML 檔，開了就能用。

**線上版**：https://cormort.github.io/pdf-row-shifter/

## 功能

- **保留原版面**：用 pdf.js 抽出文字與框線，依原始座標絕對定位，天地線／欄線／頁首都固定不動。
- **調整分頁**：`↓ 最後一列推到下頁` / `↑ 下頁第一列拉上來`，或直接拖曳任一列到新位置。
- **群組**：點一下選起點、Shift 點終點選一段，組成群組後一起搬，不會被分頁拆開（給跨行的計畫名稱用）。
- **行距自動微調**：非最後一頁的列平均分佈到表身底端，抽掉或塞入列都不會在頁尾留下突兀空白；超量時等比壓縮，不會越過地線。
- **對開表**：勾選後把單數頁（左半）＋雙數頁（右半）合成一個版面編輯，列印時再切回兩張 A4，頁碼左右各自重編。
- **就地編輯**：雙擊任一格改字，Enter 存檔、Esc 放棄。
- **對齊**：⌥（Option）點格選取，靠左／置中／靠右／水平均分／依欄線置中。
- **復原 / 重做**：⌘Z、⇧⌘Z（Windows 為 Ctrl+Z、Ctrl+Shift+Z）。
- **輸出**：瀏覽器「列印 / 存成 PDF」，A4 無邊界。

## 限制

- 需要連網（pdf.js 從 CDN 載入）。
- 只處理文字型 PDF，掃描檔沒有文字圖層。
- 編輯以 PDF 原本的文字片段為單位；美術字距的標題在原檔是一字一片段，需逐字改。
- 框線偵測假設表格有橫貫全寬的天地線，特殊版型可能要調整。
